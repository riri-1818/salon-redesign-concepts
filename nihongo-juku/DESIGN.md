# Nihongo-Juku（設計メモ・2026-10-11）

## この店はどんな場所か
- シドニーの日本語の個別指導塾。主任の Yuko Martens 先生の自宅オフィス（Sydney Olympic Park）とオンライン。授業はすべて個別で、先生が生徒ごとに教材を作る。
- 「塾」という言葉の由来（学者が自宅に弟子を取った）を、自分たちの名前の説明としてサイトに書いている。口コミは Google 5.0（24件）。
- 生徒は、HSC の高校生、JLPT を受ける人、会話を学ぶ大人、忙しい社会人、9〜11歳の子ども。目的がはっきり分かれている。

## 骨格（直前の3店と変える）
- Totonou＝左の縦レール、KUMI＝最初の画面が道具、AMANO＝雑誌の1本もの。
- ここは「ノート」。上に見出しタブ（Start／Courses／Teachers／日本語／Apply）が付いた、罫線と赤い余白線のあるページ。画面はタブで切り替える（縦スクロールは止めない）。
- 各画面のいちばん上に「今日のことば」が1語ある（塾・体験・先生・国語・申込）。サイトを見るだけで5語おぼえる。全部見ると花丸。

## この店だけの部品
1. 文を作ると授業プランが組まれる：「I want to ＿＿.」の空欄を5つの目的から選ぶ → コース・場所・1回の長さ・料金・先生の紹介・生徒の声が1枚にまとまる。料金は時間単価からその場で計算。
2. 今日のことば＋花丸：5つの画面で1語ずつ。上のタブに「Words 2/5」。
3. 申込みフォーム：プランで選んだコースと受け方を引き継ぐ。今のフォームの項目はすべて残す。
4. 赤ペン：選んだ言葉に赤い下線が引かれる（先生の添削）。

## 動き（3種類以上）
- 赤ペンの線が引かれる（SVG の線）／文の空欄の言葉が入れ替わる／料金の数字が動く／画面の切り替え／花丸が描かれる。
